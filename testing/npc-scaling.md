# Testing: NPC scaling

**Audience:** us.

Scope: `api.npcScaling` and its window (`scripts/utility-npc-scaling.js`, `manager-npc-scaling.js`, `api-npc-scaling.js`, `window-npc-scaling.js`). The engine is held by `node tools/check-npc-scaling.mjs`, which passes. Nothing below has run in Foundry. Remove an item when it passes, and delete this file when it is empty. Results go to the **Verified** line of the CHANGELOG entry, not back into this file.

Start with the harness: paste `testing/test-harness.js`, open **NPC Scaling**, and run the headless checks. They make and delete their own actors. They cover the API surface, the dnd5e field paths, a goblin scaled to CR 12 with the source untouched, rescaling without stacking, the template library and a template scaling a goblin, every refusal code, and the hook. Note which layout the `paths` check logs (6.x or 5.x). The items below are what it cannot do.

1. The toolbar. As the GM, select an NPC token. Expected: a **Scale NPC** tool in the GM tools zone of the Blacksmith toolbar, with the tooltip "Scale NPC (select an NPC token first)". Press it with no token selected. Expected: a warning telling you to select an NPC token. Log in as a player. Expected: no tool.
2. The sheet. Open an NPC's sheet as the GM and open its header menu. Expected: **Scale NPC**. Open a character's sheet. Expected: no entry. Open an NPC's sheet as a player. Expected: no entry. Open an NPC from a compendium. Expected: the entry, and scaling it creates a world actor in no folder.
3. The window, first look. Select a goblin token and press the tool. Expected: a window titled Scale NPC with the creature's name and a CR badge, the target CR already four above its own, a name suffix of "Super", and a stat / now / scaled table with rows for challenge rating, proficiency, hit points, armor class, attack bonus, spell save DC (if it casts) and damage. Switch Light, Dark and Glass. Expected: every control and the table follow the theme and stay legible.
4. Redraw. Change the challenge rating select. Expected: the table redraws with new numbers. Set it to the creature's own CR. Expected: "Nothing changes at this challenge rating". Set it below its own. Expected: negative changes, and hit points never below 1.
5. Editing in place. Press the pencil beside the suffix, type "Elite" and press Enter. Expected: text again, and the table is unchanged. Press the pencil beside **Attacks per round now** and enter 3. Expected: the creature is treated as already making three, so it is given fewer extra attacks and each hit grows by less. Press the pencil beside **Attacks per round after scaling** and enter a higher number. Expected: the **Attacks per round** row changes, the per-hit increase shrinks, and `Damage per round` stays near the table's figure. Enter 0 or 20. Expected: ignored. Change the challenge rating. Expected: the after-scaling count follows the new CR again.
6. Create. Press **Create Scaled Actor**. Expected: a toast "Scaled actor created" with the name, that opens the sheet when clicked; a new actor in the Actors directory named `<name> (<suffix>)` in the source's folder; the source unchanged.
7. The numbers on the sheet. On the new actor's sheet. Expected: CR as chosen, proficiency bonus as the table said, hit points full at the new maximum, armor class as previewed, XP as the CR's. Open one of its attacks. Expected: the damage formula itself has grown (`1d8 + 3` is now more dice, in the same die), with nothing hidden at actor level, and a Multiattack feature saying how many attacks it makes. Roll an attack. Expected: the attack total includes the bonus and the damage is the new formula. If it casts, check a spell save DC against the preview.
8. A real stat block. Scale an owlbear, a goblin boss and a spellcaster (a mage) to CR 12. Expected: the attack count follows their Multiattack text where it states one plainly, and is 1 where it does not. The numbers are plausible for CR 12 and the warning appears only where one attack carries a large bonus.
9. Rescale. Open the window on the scaled actor. Expected: a line saying it was scaled from the source, an **Open Source** button, and the same numbers as scaling the source to that CR. Create. Expected: the new actor is named from the original, not `Goblin (Super) (Elite)`.
10. Unlinked tokens. Drop one goblin and copy-paste it four times, then rename two tokens. Open the window on two of them. Expected: two windows, one per token, and pressing the tool again on the first focuses it. Damage one token, then scale it. Expected: the preview and the new actor reflect that token, not its siblings.
11. Encounter. Put the scaled actor on the canvas. Expected: the encounter bar counts it at its new CR.
12. The hook. In the console: `Hooks.on('blacksmith.npcScaling.applied', console.log)`, then scale. Expected: one log with `source`, `result`, `spec` and `output`.
13. dnd5e 5.x. On a 5.x world, run the harness suite. Expected: `paths` passes with the `system.bonuses` layout, and scaling a goblin writes attack, damage and AC. This is the one place the 5.x column of the path table is proved.
14. Templates, the picker. In the window press **Template** in the Scale by switch. Expected: a row of chips (Weakened, Elite, Champion, Super), the first selected, a line saying what it does, the name suffix now reading the template's name, and the table redrawn. Pick another chip. Expected: the table and the suffix follow. Type your own suffix, then pick another chip. Expected: the suffix follows the chip again. Check Light, Dark and Glass.
15. Templates, the editor. Press **+**. Expected: a dialog prefilled from the preview you were looking at (a CR retarget shows as a CR step, a hit point percentage and totals), with an empty name. Save it with no name. Expected: the dialog reopens with a message. Name it "Elite". Expected: rejected as a duplicate. Name it "Test", save. Expected: back in the window, the new chip selected. Press the pencil, change the damage and save. Expected: the table moves.
16. Templates, a template on another creature. Open the window on a creature of a very different size (a goblin, then a dragon) and pick Elite on each. Expected: hit points are 50% on top of each creature's own, not the same flat amount. Create from each. Expected: the new actor is named `<name> (Elite)`, at the CR the preview said.
17. Templates, delete. Select "Test" and press the trash. Expected: a confirm naming it; confirm; the chip is gone and the first template is selected. Delete every template. Expected: "No templates yet", and a message in place of the table. Press **+** and make one. Expected: it works. Reload Foundry. Expected: the library is as you left it (the four starting templates did not come back).
18. Templates, export and import. Press the export button. Expected: a download named `npc-scaling-templates-<world>-<date>.json`. Open it. Expected: an envelope with `type`, `version` and `templates`. Delete a template, press import, choose the file, choose **Merge**. Expected: "1 added, N updated", and the deleted one is back. Import it again with **Replace All**. Expected: the library is exactly the file. Import a non-template JSON file. Expected: an error saying so, and nothing changed.
19. Guidelines, the dialog. In the Scale NPC window press **Guidelines**. Expected: a dialog naming the table in use ("DMG 2014 (bundled)") and a note that the 2024 books publish none, with **Build from Compendium** and Close. The window's hint under the table also names the table in use.
20. Guidelines, building. Press **Build from Compendium**. Expected: a list of every actor compendium with the ones you chose for monsters in settings ticked (or the system's 2024 actors if none). Untick everything and press **Read Creatures**. Expected: rejected with a message. Tick the 2024 actors and press it. Expected: a progress notification, taking a few seconds, then a dialog with a row per challenge rating: the number of creatures, and each figure with the old one struck through where it changed. Shaded rows are estimates. Expected: high challenge ratings with few creatures are shaded "too few creatures", and any row where armor class or hit points were bent to stop falling says "smoothed". Read the figures: a CR 5 creature should have an armor class around 15 and a CR 20 one around 19 to 20.
21. Guidelines, using it. Press **Cancel**. Expected: nothing changed; the window still names the bundled table. Build again and press **Use This Table**. Expected: a notification, the window's hint now reads "Built from ...", and the preview for the same creature and CR has moved. Create a scaled actor. Expected: it is scaled by the new figures. Reload Foundry. Expected: still the built table.
22. Guidelines, reset. Press **Guidelines** again. Expected: the dialog now says it was built from the pack, on what date and from how many creatures, and offers **Use DMG 2014**. Press it. Expected: the bundled table again and the old preview numbers.
23. Actions, the formulas. Scale an owlbear to CR 12. Open its Beak and Claws. Expected: each damage formula has grown in its own dice, the flat part kept, and the Claws and Beak grown in proportion (the stronger one gaining more). Open the owlbear itself. Expected: unchanged. Scale a creature with a breath weapon or another save-based attack. Expected: its save damage grew too, where the old version left it alone.
24. Actions, Multiattack. Scale a creature with no Multiattack (a badger, a goblin) from a low CR to CR 8. Expected: a Multiattack feature on the new actor saying three attacks, and a note that it was scaled. Scale a creature that already has one (an owlbear). Expected: its own text kept, with a paragraph appended after it. If you chose a feature compendium in settings that holds a Multiattack, expected: the new feature carries that item's icon and structure; with none chosen, a plain feature with the default icon.
25. Actions, the limits. Scale a creature whose damage is only spells (a mage) up. Expected: the spells are not changed, the row for damage says it was written as a bonus, and a spell attack still hits harder. Scale a creature down. Expected: dice shrink but never below one die, and no attacks are added.
26. Actions, a CR 0 beast. Scale a badger to CR 4. Expected: two attacks, each hit growing by about half what it would on one, and a warning only if a hit still grows past three times its own average.
